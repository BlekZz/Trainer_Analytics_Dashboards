# Quick Start：完整對話示範

> 此檔展示「使用者觸發 skill → AI 執行完整流程」的標準對話樣態。

---

## 範例 1：完整輸入（最理想情況）

### 使用者輸入

```
依規格手冊，幫我做一份新的訓練 dashboard。

產業：SaaS 訂閱型專案管理工具（類似 Asana / ClickUp）
訓練主題：產品啟用漏斗 + 流失歸因
差異化偏好：
  - 視覺要更冷靜（中性灰主體，藍色強調）
  - 教學要更偏批判性質疑（L3·A 比例提高）
  - 結構改成漏斗式 4 頁
```

### AI 執行 Phase 1（規格鎖定）

```markdown
## 規格初稿（請確認）

### 結構（4 頁漏斗式）
P1: 註冊 → 啟用（top of funnel）
P2: 啟用 → 活躍（engagement）
P3: 活躍 → 留存（retention）
P4: 訓練題 + 設計選擇揭露（教學總結）

### 資料錨點（預告）
- 總註冊：32,847（B2B SaaS 中小型量級）
- 啟用率：54.2%（行業平均偏中）
- MAU：14,205
- 月 Churn：6.8%（中型 SaaS 警戒線邊緣，當教學點）
- ARR：NT$8,640 萬
- 客單價 ARPU：NT$507/月

### 圖表清單（共 14 張）
P1（4 張）：註冊來源分佈 / 註冊→啟用時間分佈 / 啟用率月趨勢 / 啟用條件達成熱圖
P2（4 張）：DAU/MAU 趨勢 / 功能採用率瀑布圖 / 邀請成員人數分佈 / 工作流創建頻次
P3（4 張）：Cohort 留存矩陣 / 月度 Churn 折線 / 流失歸因 Sankey / Net Retention 趨勢
P4（2 張）：CAC vs LTV 散佈圖 / 漏斗階段衝擊矩陣

### 問題清單（共 22 道 + 5 訓練題）
P1 (5 題)：1×L1·F、1×L1·I、1×L2·F、1×L2·I、1×L2·A
P2 (5 題)：1×L1·I、2×L2·I、1×L2·A、1×L3·I
P3 (7 題)：2×L2·I、2×L2·A、2×L3·I、1×L3·A
P4 (5 訓練題)：T1 流失歸因策略 / T2 漏斗階段優先級 / T3 啟用條件批判 / T4 缺失維度 / T5 KPI 定義質疑

### 教學設計
- 陷阱主題（5 個此份特有）：
  ① DAU/MAU 比值的「分母陷阱」
  ② Cohort 矩陣「右下角樣本量太小」推論失效
  ③ 月 Churn vs 年 Churn 不可線性換算
  ④ 啟用條件定義不同會導致 30% 差異
  ⑤ LTV/CAC 比值忽略付款週期變動

### 差異化 vs 基準範本
- 視覺：藍 → 中性灰主體 + 鋼藍強調 / radius 14 → 8 / hard-line shadow
- 教學：難度分佈批判型（L3·A 多）/ 陷阱密度加倍（I 題也加）
- 結構：3 頁維度分頁 → 4 頁漏斗分頁 / 訓練題拆獨立頁

確認以上規格後，AI 才繼續 Phase 2（資料生成）。
```

### 使用者確認

```
OK，但啟用條件熱圖改成漏斗階段轉換率柱狀圖（熱圖在這個樣本量下會雜亂）。其他都好。
```

### AI 執行 Phase 2-5（簡述）

```
✓ Phase 2: 生成 DATA.json，跑完 9 條 assertion → 全部通過
✓ Phase 3: HTML 建構完成，14 張圖全部繪製
✓ Phase 4: 差異化套件套用（中性灰主色 / hard-line / 4 頁漏斗 / 批判型分佈）
✓ Phase 5: Playwright 自動驗證 → 18 項全綠

交付物：
1. saas-funnel-dashboard.html (約 110KB)
2. DATA.json
3. CHANGELOG.md（差異化記錄）
4. verification-report.txt
```

## 範例 2：模糊輸入（需要追問）

### 使用者輸入

```
幫我換個產業重做一份
```

### AI 回應

```markdown
## 需要更多資訊才能生成

範本基準是 B2C 電商會員 × 交易分析。換產業時請告訴我：

1. 產業情境（必要）
   例：SaaS / 餐飲連鎖 / 線上教育 / 訂閱媒體 / 健身房 / 二手平台

2. 訓練主題（必要）
   例：funnel 漏斗 / 留存分析 / A/B test / 流量歸因 / 成本毛利結構

3. 差異化偏好（可選，沒指定我會隨機抽 3 個元素）
   - 視覺軸：色系、整體調性、字型、圖表變體
   - 教學軸：陷阱密度、F/I/A 嚴格度、難度分佈、訓練題類型
   - 結構軸：頁數、分組邏輯、KPI 數量、起手頁
```

## 範例 3：同產業不同切角

### 使用者輸入

```
產業同樣是 B2C 電商，但這次想訓練「促銷 A/B test 解讀」能力，
其他都讓你自由發揮。
```

### AI 執行

```markdown
## 規格初稿（同產業不同切角）

⚠ 此份與前一份同為 B2C 電商，依規範教學軸必須大幅差異化，
   資料錨點可接近（讓學員聚焦能力而非適應新數字）。

### 結構（3 頁）
P1: 實驗總覽（baseline vs variant 整體對比）
P2: 分群影響分析（不同會員等級 / 來源渠道 / 品類的反應差異）
P3: 統計顯著性 + 訓練題

### 教學重點（vs 前一份的最大差異）
前一份：訓練「會員結構推論 + 跨頁交叉」
這份：訓練「實驗結果解讀 + 統計批判」

### 陷阱主題（5 個此份特有）
① 平均提升 +X% 但顯著性 p > 0.05（樣本量不足陷阱）
② 整體沒效但某分群有效 → 是真效應還是 multiple testing
③ 短期觀察期未涵蓋退貨週期 → 數字會回吐
④ Lift 在頂尖客群最大但他們本來就會買（增量陷阱）
⑤ 用變異率比平均值，掩蓋大客單價影響

### 訓練題（4 道，全是 L3·A 批判型）
T1: 「這個 +8.4% lift 結果，你會推薦 PM 全面 rollout 嗎？」（要找出 3 個質疑點）
T2: 「實驗只跑 7 天就停了，數據看起來顯著，但你的建議是？」
T3: 「Variant 在新客群效果好但對忠誠客群效果差，怎麼解讀？」
T4: 「這個 dashboard 還缺哪些分析才能下決策？」（5 個維度）

### 資料錨點（小調整貼近 A/B test 情境）
- 實驗組樣本：22,140 vs 對照組 22,156
- 平均 lift：+8.4%（但分群差異很大）
- p value: 0.038 / Confidence interval: [+1.2%, +15.6%]
- 細分到 4 個會員等級 × 3 個品類的二維 lift 矩陣

確認後執行 Phase 2-5。
```

## 範例 4：差異化過頭的提醒

### 使用者輸入

```
我要超級不一樣的：4 頁 / 紫色 / 動畫炫一點 / 訓練題改 8 道 / 不要設計揭露區 / chip 改 emoji
```

### AI 回應

```markdown
⚠ 部分要求觸發「差異化不可妥協元素」（模組 D.5）：

✓ 可接受的差異化
- 4 頁分頁 → OK
- 紫色主色 → OK
- 動畫加長 → OK
- 訓練題改 8 道 → OK
- chip 改 emoji 標註 F/I/A → OK（但要保留 F/I/A 可識別性，建議用 📍 ⚡ 🤔）

✗ 不可省略元素
- 設計選擇揭露區塊（D.5 教學核心，必須存在）
  → 可改為「分析師日記」敘事風格但不可移除

調整後執行嗎？或你想討論為什麼設計揭露不可省？
```

## 範例 5：使用者只給產業

### 使用者輸入

```
做一份線下零售（連鎖超商型態）的 dashboard
```

### AI 追問

```markdown
線下零售連鎖訊息很多面向可訓練，請選一個重點：

a) 門市績效對比（哪些店在賺、為什麼、要關還是擴）
b) 商品結構分析（品類組合、客單價結構、損益）
c) 客流與時段運營（高峰時段、收銀台配置、巔峰人力）
d) 庫存週轉與供應鏈（即期品、缺貨率、補貨節奏）
e) 會員機制效益（會員 vs 非會員消費、會員等級 ROI）

哪一個？或要不要混合兩個（例：a + e）？
```
